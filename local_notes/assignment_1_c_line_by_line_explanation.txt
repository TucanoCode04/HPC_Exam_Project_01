uLine-by-line explanation of src/Davide/assignment_1.c
=====================================================

This note is local-only. The folder local_notes/ is added to .gitignore so it
does not get pushed.

Assignment context
------------------
Assignment_part_1_OpenMP.pdf asks for an OpenMP simulator for the two-
dimensional damped wave equation:

    d2u/dt2 + gamma * du/dt = c^2 * Laplacian(u)

The lab objective is to move from the continuous equation u(x, y, t) to a
discrete M x M grid over N time steps. Each time step is a matrix of wave
heights. The program must compute those matrices using OpenMP and save each
completed matrix as a binary PGM frame in the sim/ folder using names like
frame_00001.pgm. Those frames can then be combined into an MP4 video with
FFmpeg.

PDFs/parameters_part_1.pdf gives the assigned values for student ID 352165:

    gamma = 0.067
    c = 0.59
    i0 = M/2
    j0 = M/2
    u(i0,j0) = 56

The code is written so gamma, c, dt, dx, M, N, impulse position, amplitude,
thread count, scale, and output folder are provided as command-line arguments.

How the code matches the lab
----------------------------
The assignment says to initialize an M x M matrix, apply an initial impulse,
compute the wave evolution for N steps, parallelize the computation with
OpenMP, and write every matrix as a PGM image. assignment_1.c does exactly that:

    1. Read and validate simulation parameters.
    2. Allocate three M x M matrices: previous, current, and next.
    3. Place the initial impulse at the requested grid point.
    4. Repeatedly compute u at the next time step with a finite-difference
       update for the damped 2D wave equation.
    5. Use OpenMP on the expensive grid loops.
    6. Save every time step as a P5 binary PGM frame.

Numerical formula used in compute_next
--------------------------------------
The core update is:

    next = (2 * current
            - (1 - 0.5 * gamma * dt) * previous
            + (c * dt / dx)^2 * laplacian(current))
           / (1 + 0.5 * gamma * dt)

This is the discrete version of the damped wave equation from the assignment.
The Laplacian term makes the wave propagate across the 2D grid. The gamma terms
reduce amplitude over time, modeling damping.
